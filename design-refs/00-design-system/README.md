# 벨로르 공식 디자인 시스템 원본

이 폴더의 `Wanted Design System (Community).fig`는 향후 벨로르 웹 개편에 사용할
컴포넌트·레이아웃·상태 설계 기준 원본이다.

## 사용 원칙

- 먼저 저장소 루트의 `DESIGN.md`를 확인한다.
- Figma 원본에서는 컴포넌트 구조, 간격, 정렬, 상태, 접근성, 반응형 원칙을 참고한다.
- Wanted의 브랜드명, 로고, 콘텐츠 문구를 벨로르에 복사하지 않는다.
- 색상, 브랜드 표현, 화면별 요구사항은 벨로르의 `DESIGN.md`와 `design-refs/`를 따른다.
- 새 화면은 임의 스타일을 추가하기 전에 기존 벨로르 토큰과 공통 컴포넌트를 재사용한다.

## 보관 파일

- `Wanted Design System (Community).fig`: Figma 원본
- `Pretendard-original.zip`: 전달받은 프리텐다드 전체 패키지 원본

웹사이트에 직접 사용하는 최적화된 폰트는
`assets/fonts/pretendard/PretendardVariable.woff2`에 별도로 보관한다.

원본 파일은 직접 덮어쓰지 않는다. 개편 작업에서 수정본이 필요하면 복제본을 만들고
날짜 또는 버전을 파일명에 기록한다.
