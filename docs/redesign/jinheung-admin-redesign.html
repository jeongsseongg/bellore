Jinheung Mall · v4

보시던 스타일 그대로,
쓰기만 편하게

토스·원티드·헤이딜러의 밝은 카드, 파랑 포인트, 세그먼트는 그대로 둡니다. 바꾸는 건 메뉴 체계와 화면 순서입니다. 메뉴를 5개에서 4개로 줄이고, 하루 순서대로 놓고, 휴대폰 기준으로 다시 그렸습니다.

그대로 두는 것

  • 토스 스타일 — 흰 카드, 테두리 없음, 둥근 모서리
  • 파랑 #3182F6 단일 포인트 색
  • 토스 세그먼트 — 회색 트랙 + 흰 알약
  • 원티드 — 넓은 여백, 밝은 바탕
  • 해요체 문구, 큰 글자·큰 버튼

바꾸는 것

  • 메뉴 5개 → 4개 (오늘 · 주문 · 상품 · 더보기)
  • 데스크톱 우선 → 휴대폰 우선 + 하단 탭
  • KPI 대시보드 → 「오늘 할 일」 단계 카드
  • 헤이딜러식 진행률 막대 + 하단 고정 버튼
  • 「재고 한 번에 넣기」 화면 신설
01

지금 구조가 불편한 이유

색 문제가 아니라 순서와 개수 문제입니다.

순서

메뉴가 시스템 순서로 되어 있어요

상품 관리 · 주문 관리 · 고객 관리 · 설정. 이건 데이터베이스 이름이지 사장님이 하루를 보내는 순서가 아닙니다.

→ 하루 순서로 다시 배치
개수

메뉴가 5개라 휴대폰에 안 들어가요

하단 탭은 4개가 한계입니다. 5개가 되면 글자가 작아지고 잘못 눌리기 쉬워집니다.

→ 매일 안 쓰는 3개는 「더보기」로
기기

데스크톱 기준으로 만들어졌어요

사장님은 사무실 책상이 아니라 작업장에서 휴대폰으로 봅니다. 새벽에 주문이 들어옵니다.

→ 휴대폰이 기본, 데스크톱은 같은 구조를 넓게
첫 화면

숫자만 있고 할 일이 없어요

0 · 0 · 0 · 70을 보고 스스로 해석해야 합니다. 숫자는 상태일 뿐 다음 행동이 아닙니다.

→ 「오늘 할 일」을 순서대로 (헤이딜러 방식)
막힘

재고 70개를 하나씩 고쳐야 해요

모든 상품 재고가 0인데, 채우려면 수정 버튼을 70번 눌러야 합니다. 현실적으로 불가능합니다.

→ 「재고 한 번에 넣기」 신설
이동

같은 메뉴가 두 군데 있어요

왼쪽 사이드바 5개와 상단 탭 5개가 완전히 같습니다. 지금 어디 있는지 표시도 두 군데서 따로 납니다.

→ 상단 탭 삭제. 세그먼트는 목록 필터로만
02

메뉴를 하루 순서로

이번 개편에서 가장 중요한 변화입니다.

지금 · 시스템 순서 5개
  • 1상품 관리 테이블 이름
  • 2주문 관리 테이블 이름
  • 3고객 관리 테이블 이름
  • 4주문·입금 설정 거의 안 씀
  • 5계정 보안 1년에 한 번
→
개편 · 하루 순서 4개
  • 1오늘 켜자마자 할 일
  • 2주문 하루 수십 번
  • 3상품 재고·가격
  • 4더보기 고객·설정·보안
  • 「오늘」이 새로 생기는 첫 화면입니다. 켜자마자 지금 뭘 해야 하는지가 보입니다.
  • 고객·설정·보안은 매일 쓰지 않으므로 「더보기」로 내립니다. 하단 탭 자리를 차지할 이유가 없습니다.
  • 데스크톱도 같은 4개를 왼쪽에 폅니다. 기기를 바꿔도 위치가 같아야 헷갈리지 않습니다.
  • 세그먼트(토스 알약)는 화면 안에서 목록을 거를 때만 씁니다. 화면 이동에 쓰면 지금 문제로 되돌아갑니다.

「재고 한 번에 넣기」 — 신설

개발 지시

  • 「오늘」은 새로 만드는 화면입니다. 규칙 3개로 목록을 만듭니다 — 재고 0인 상품 수 > 0, 계좌 3필드 중 빈 값, 이름 없는 고객 수 > 0. 전부 해결되면 카드가 사라지고 그 자리에 오늘 매출이 들어옵니다.
  • 진행률 막대와 「1 / 4 완료」는 헤이딜러 방식입니다. 얼마나 남았는지 보여주면 끝까지 하게 됩니다.
  • 단계 번호는 지금 할 것만 파랑, 끝난 건 초록 체크, 나머지는 회색. 어디부터 손댈지 고민이 없습니다.
  • 맨 아래 파랑 버튼은 화면에 고정(position:sticky; bottom:0)됩니다. 스크롤을 내려도 다음 행동이 항상 보입니다.
  • 재고 한 번에 넣기가 이번 개편에서 실질적으로 가장 큰 기능 추가입니다. − / + 는 44×44px, 숫자를 탭하면 키패드, 저장 바는 하단 고정.

05

작업 순서

1~3번이 이번 개편의 전부입니다. 색은 건드리지 않으니 작업량이 지난번보다 적습니다.

  1. 메뉴를 4개로 다시 짠다오늘 · 주문 · 상품 · 더보기. 휴대폰은 하단 탭, 데스크톱은 왼쪽 세로. 상단 탭 5개는 삭제합니다. 가장 중요한 변화입니다.
  2. 「오늘」 화면을 새로 만든다규칙 3개(재고 0 / 계좌 빈값 / 이름 없는 고객)로 단계 목록 + 진행률 막대. 전부 해결되면 매출 화면으로 바뀝니다.
  3. 「재고 한 번에 넣기」를 만든다70개를 하나씩 여는 건 불가능합니다. 이게 없으면 진흥몰은 열 수 없습니다.
  4. 휴대폰 화면을 먼저 맞춘다390px 기준으로 먼저 완성하고, 데스크톱은 같은 컴포넌트를 넓게 폅니다. 반대로 하면 휴대폰이 항상 부실해집니다.
  5. 하단 고정 버튼을 넣는다position:sticky; bottom:0. 「오늘」과 「재고 넣기」에 우선 적용합니다.
  6. 색상 매핑표를 만든다4번의 FLOWER_COLOR. 색 점과 재고 막대가 여기서 나옵니다.
  7. 상태를 계산값으로 바꾼다재고 0 → 자동 품절. "0단인데 판매중"이 구조적으로 나올 수 없게 합니다.
  8. 고객 이름 ???를 고친다인코딩(UTF-8) 확인 → 없으면 이메일 앞부분으로 대체 → "이름 없음" 칩.
하지 말 것 — ① 하단 탭을 5개 이상으로 늘리기 ② 세그먼트로 화면 이동시키기(원래 문제로 복귀) ③ 파랑 말고 다른 포인트 색 추가 ④ 데스크톱을 먼저 만들고 휴대폰을 나중에 ⑤ 상품코드 체계·단·부쉬 단위 건드리기.
