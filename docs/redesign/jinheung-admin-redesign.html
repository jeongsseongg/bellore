01

지난 시안이 토스가 아니었던 이유

방향을 잘못 잡았습니다. 무엇이 달라졌는지 먼저 짚습니다.

고침

어두운 사이드바를 없앴습니다

진한 초록 사이드바는 옛날 어드민의 대표적인 신호입니다. 토스에는 어두운 면이 없습니다.

→ 흰 사이드바 + 선택된 항목만 연한 파랑 알약
고침

테두리를 다 지웠습니다

카드마다 1px 회색 테두리를 두르면 화면이 격자로 잘려 보입니다. 토스는 선 대신 배경 차이로 나눕니다.

→ 회색 바탕 #F9FAFB 위에 흰 카드, 테두리 0
고침

모서리를 더 둥글게

14~16px은 어중간합니다. 토스는 카드 20~22px, 버튼 14px, 아이콘 타일 16px로 확실히 둥급니다.

→ 카드 22px · 버튼 14px · 입력칸 14px
고침

표를 리스트로 바꿨습니다

회색 헤더 줄과 세로 칸이 있는 표는 엑셀처럼 보입니다. 토스에는 표가 거의 없습니다.

→ 큼직한 행 + 왼쪽 둥근 색 타일 + 오른쪽 값
고침

이모지를 아이콘으로

🌸 같은 이모지는 운영체제마다 다르게 나오고 싸구려로 보입니다.

→ 선 아이콘(SVG) + 파스텔 배경 타일
고침

말투를 바꿨습니다

"아직 주문이 없습니다"는 시스템 말투입니다. 토스는 사람이 말하듯 씁니다.

→ "오늘은 아직 주문이 없어요" · 해요체 통일

한 줄로 요약하면

지난 시안은 테두리로 칸을 나눈 관리자 화면이었고, 이번 시안은 여백으로 칸을 나눈 서비스 화면입니다. 같은 정보를 담고 있지만 화면을 읽는 방식이 다릅니다.

02

토스 규칙 8가지

"토스 느낌"은 감이 아니라 지킬 수 있는 규칙입니다. 이 8개를 지키면 토스처럼 보입니다.

규칙구체적으로
1테두리 대신 배경화면 바탕 #F9FAFB, 카드 #FFFFFF. 카드에 border를 넣지 않습니다. 행 사이만 #E5E8EB 1px.
2회색은 5단계만#191F28 본문 · #4E5968 설명 · #8B95A1 보조 · #E5E8EB 선 · #F2F4F6 채움. 그 사이 값을 새로 만들지 않습니다.
3파랑은 하나#3182F6. 누를 수 있는 것과 지금 선택된 것에만 씁니다. 장식으로 쓰지 않습니다.
4글자는 굵고 크게제목 800, 본문 500~600. 자간 -0.02em ~ -0.045em으로 좁힙니다. 얇은 글씨를 쓰지 않습니다.
5모서리는 확실히카드 22px · 버튼 14px · 입력칸 14px · 아이콘 타일 16px · 칩 10px.
6여백을 아끼지 않기카드 안쪽 26~32px, 카드 사이 12~14px. 좁혀서 더 넣지 않습니다.
7한 화면에 파랑 버튼 하나나머지는 회색 #F2F4F6 버튼. 무엇을 눌러야 할지 고민이 생기지 않게 합니다.
8사람처럼 말하기해요체. "오늘은 아직 주문이 없어요", "재고를 채우면 판매를 시작할 수 있어요".
03

토큰 — 복사해서 쓰세요

이 값이 곧 토스 느낌입니다. 색과 크기를 코드에 직접 쓰지 말고 전부 변수로 참조합니다.

/* ============ 진흥몰 디자인 토큰 v2 (Toss) ============ */
:root{
  /* 파랑 — 누를 수 있는 것과 선택된 것에만 */
  --blue:#3182F6;  --blue-strong:#1B64DA;  --blue-weak:#E8F3FF;

  /* 회색 5단계 — 이 사이 값을 새로 만들지 않습니다 */
  --ink:#191F28;   /* 본문·제목 */
  --sub:#4E5968;   /* 설명 */
  --dim:#8B95A1;   /* 보조·플레이스홀더 */
  --line:#E5E8EB;  /* 행 사이 구분선 (카드 테두리 아님) */
  --fill:#F2F4F6;  /* 입력칸·회색버튼 채움 */

  /* 면 — 카드에 border 를 넣지 않습니다 */
  --bg:#F9FAFB;    /* 화면 바탕 */
  --card:#FFFFFF;  /* 카드 */

  /* 상태 — 색만으로 구분 금지, 항상 글자와 함께 */
  --red:#F04452;    --red-weak:#FFF0F1;    /* 품절 */
  --green:#00B25D;  --green-weak:#E8F8F0;  /* 판매중·완료 */
  --amber:#FF9500;  --amber-weak:#FFF6E5;  /* 입금 대기 */

  /* 글자 — 나이 배려 기본값 */
  --f-body:17px;  --f-label:15px;  --f-cap:14px;
  --f-sec:19px;   --f-page:32px;   --f-big:38px;

  /* 모서리 — 어중간하게 두지 않습니다 */
  --r-card:22px;  --r-btn:14px;  --r-input:14px;
  --r-tile:16px;  --r-chip:10px;

  /* 규격 — 이 값보다 작게 만들지 않습니다 */
  --h-btn:54px;  --h-btn-sm:46px;  --h-input:56px;
  --pad-card:28px;  --gap-card:14px;  --maxw:1180px;
}

/* 카드 — 이 3줄이 전부입니다. border 없음, 그림자 없음 */
.card{ background:var(--card); border-radius:var(--r-card); padding:var(--pad-card); }

/* 글꼴 — 자간을 좁혀야 토스처럼 보입니다 */
body{
  font-family:Pretendard, -apple-system, "Apple SD Gothic Neo", sans-serif;
  font-size:var(--f-body); line-height:1.55;
  letter-spacing:-0.02em;    /* ← 이거 빼면 토스 느낌이 안 납니다 */
  word-break:keep-all;
}
h1,h2,.h1{ font-weight:800; letter-spacing:-0.04em; }

개발 지시

  • 표 헤더 줄을 없앱니다. 값 자체가 무엇인지 보이게 만듭니다 — "2,000원", "단 · 18부쉬", "품절"은 라벨이 없어도 읽힙니다.

작업 순서

1~4번만 해도 화면이 완전히 달라 보입니다. 하루면 끝납니다.

  1. 토큰 CSS를 전역에 넣기3번 블록 복사. 하드코딩된 색·크기를 전부 var(--*)로 바꿉니다.
  2. 카드에서 border를 전부 지우기border:1px solid …를 검색해서 삭제. 배경만 흰색으로 두고 border-radius:22px. 이 하나가 가장 큰 변화입니다.
  3. 바탕을 #F9FAFB로흰 바탕 위 흰 카드는 안 보입니다. 화면 바탕이 회색이어야 카드가 떠 보입니다.
  4. 자간 -0.02em 걸기body에 letter-spacing:-0.02em, 제목에 -0.04em. 이거 하나로 인상이 크게 바뀝니다.
  5. Pretendard 서버에 올리기CDN 링크 금지. word-break:keep-all도 함께.
  6. 상단 탭 5개 삭제사이드바에 "운영 현황" 추가 + 판매/설정 그룹 분리.
  7. 세그먼트·버튼·칩을 컴포넌트로화면마다 따로 만들지 않습니다.
  8. 표를 리스트로 바꾸기헤더 줄 없애고, 왼쪽에 둥근 타일 아이콘.
  9. 상태를 계산값으로재고 0 → 자동 품절. "0개 · 판매중"이 나올 수 없게.
  10. 문구를 해요체로 전부 고치기6번 표 그대로. 색을 바꾸는 것만큼 효과가 큽니다.
하지 말 것 — ① 카드에 테두리 다시 넣기 ② 어두운 사이드바 ③ 파랑 말고 다른 포인트 색 추가 ④ 세그먼트로 화면 이동 ⑤ 더 많이 넣으려고 글자·버튼 줄이기 ⑥ 상품 코드 체계·단·부쉬 단위 건드리기.
