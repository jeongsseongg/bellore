코덱스 작업 지시

지금 폼은 index.html의 #compare 섹션 안 한 장짜리 <form>입니다. 필드 이름(name)은 그대로 두고 화면만 단계로 나눕니다. 그래야 저장·서버 쪽을 건드리지 않습니다.

  1. index.html — 한 폼을 단계로 감싸기

    • <form>은 하나로 유지. 안쪽을 <div class="qstep" data-step="1">…로 나누고 현재 단계만 보이게 합니다
    • 기존 name="brand" model ref year parts memo name phone 그대로 씁니다
    • 브랜드 <select>는 숨긴 채 유지하고, 로고 버튼을 누르면 값만 채웁니다 (기존 제출 로직 그대로 동작)
    • 상단에 진행 바 .qbar + 단계 표시 1 / 5 추가

  2. 분기 두 개

    • Q1 없어요 → Q1-A(구성품 종류 · 스탬핑) 건너뜀, parts 비움
    • Q2 몰라요 → Q2-A 건너뜀, 사진을 필수로 바꾸고 model에 "모름(사진 확인 요청)"을 넣습니다

  3. 삭제할 것

    • 구성품 보유 select(326~333줄 부근) — Q1-A와 중복
    • 상태 · 등급 입력 — 고객이 스스로 매기지 않습니다. 감정 후 관리자가 부여
    • 목록 필터의 .qf-chip-grade는 그대로 둡니다(판매 상품 필터라 별개)

  4. 확인 화면 자동 기입

    마지막 단계에서 앞 단계 입력값을 읽어 요약 카드를 그립니다. 새 저장소를 만들지 말고 폼 자체의 값을 그대로 읽으세요(form.elements).

  5. styles.css · sw.js

    • 딥그린 토큰 --gr:#24312A / --gr-soft:#EEF2EF
    • 선택 카드 .pick · 옵션 .opt · 브랜드 .brand 상태는 테두리 + 연딥그린 배경으로 통일
    • sw.js VERSION 올리기 (현재 bellore-v178-ai-log)

주의

  • 제출 payload를 바꾸지 않습니다. 화면만 단계로 나눕니다 — DB·Edge Function 수정 없음.
  • 중간에 나가도 답이 남게 임시 저장(localStorage) 하되, 연락처는 저장하지 않습니다.
  • 단계마다 뒤로가기가 앞 단계로 가야 합니다. 브라우저 뒤로가기로 화면이 통째로 닫히면 안 됩니다.
  • '몰라요' 경로에서 사진 없이 제출되지 않게 막습니다.

확인 부탁드립니다

  • 질문 순서 — 구성품 → 모델 → 사진 순으로 했습니다. 사진을 맨 앞으로 뺄지.
  • 스탬핑 형식 — "2022. 04 · 서울 롯데본점" 한 칸으로 합쳤습니다. 날짜만 받을지.
  • 기타(작성)를 고르면 짧은 입력 한 줄이 열리게 했습니다. 맞는지.
  • 브랜드 그리드에 넣을 8개 순서 — 롤렉스 · 까르띠에 · 오메가 · 파텍 · AP · 튜더 · 샤넬 · 위블로.
  • 상태 · 등급 삭제 확정 — 등급은 감정 후 관리자가 부여하는 것으로 정리했습니다.
