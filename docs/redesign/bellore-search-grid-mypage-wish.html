시세는 어디서 오나

이미 있는 watch_market_prices 테이블을 그대로 씁니다. 화면용 집계는 아래 뷰 하나면 됩니다 — 서버 함수도, 새 테이블도 필요 없습니다. 

-- 검색 화면 시세 블록용 (재실행 안전)
create or replace view public.v_market_search as
with r as (
  select reference_number, brand, model,
         avg(price_krw) filter (where scraped_at > now() - interval '30 days') as p30,
         avg(price_krw) filter (where scraped_at between now() - interval '60 days'
                                                    and now() - interval '30 days') as p60,
         count(*)       filter (where scraped_at > now() - interval '30 days') as n30
    from public.watch_market_prices
   where price_krw is not null
   group by reference_number, brand, model)
select reference_number, brand, model,
       round(p30)                              as price_30d,
       round((p30 - p60) / nullif(p60,0)*100, 1) as change_pct,
       n30                                     as sample_count
  from r
 where n30 >= 5            -- 표본 5건 미만은 숨김 (오해 방지)
 order by n30 desc
 limit 20;

개발 메모

  • 인기 검색어는 지금 POPULAR_KEYS 배열에 하드코딩돼 있습니다. search_logs가 쌓이고 있으니 최근 7일 검색 수 상위 10개로 바꾸고, 등락률은 위 뷰에서 조인합니다.
  • 표본이 5건 미만이면 아예 빼세요. 2~3건 평균을 "시세"로 보여주면 그 가격을 믿고 왔다가 항의가 들어옵니다.
  • 등락 색은 국내 관행대로 상승 빨강 #C0392B · 하락 파랑 #1F6FB2. 색만 쓰지 말고 ▲▼ 기호와 숫자를 함께 둡니다.
  • 최근 본 시계는 로그인 없이도 남습니다(로컬 저장). 로그인하면 계정으로 합칩니다. 최대 20개, 오래된 것부터 밀어냅니다.
  • 가로 스크롤은 scroll-snap-type:x mandatory로 카드가 딱딱 맞춰 서게 합니다. 손가락으로 밀 때 어중간하게 걸치지 않습니다.
