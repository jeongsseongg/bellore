3. 파일별 작업 순서

  1. styles.css — 토큰과 공통 부품

    위 :root 교체 후, 아래 클래스의 border-radius와 색만 새 토큰으로 바꿉니다. 구조·클래스명은 그대로 둡니다.

    • .hcard / .hcard-img / .hcard-brand / .hcard-price — 홈·카테고리 상품 카드
    • .cat-chip — 상단 카테고리 (알약 → 밑줄 탭)
    • .header-search — 검색칸 (회색 알약 → 검정 1px 사각)
    • .btn / .btn-primary — 라운드 0, 높이 52px
    • .tabbar / .tab-item / .tab-wish-badge — 활성 테두리 제거, 배지는 점
    • .brand-circle — 원형 유지하되 로고는 filter:grayscale(1)

  2. index.html — 구조가 필요한 곳만

    대부분 CSS로 끝납니다. 마크업이 필요한 것은 세 가지입니다.

    • 섹션 제목을 영문 + 한글 두 줄로 (.section 안 제목 요소)
    • 마이페이지 메뉴를 ORDER / ACTIVITY 두 묶음으로 분리
    • 마이페이지 배너 영역 — 등록된 배너가 없으면 hidden 처리(점선 자리표시 제거)

  3. script.js — 렌더 문자열 3곳

    카드 HTML을 만드는 함수의 클래스는 그대로 두고, 추가 요소만 넣습니다.

    • fillHomeSaleGrid 계열(#homeOnSale .home-sale-grid) — 가격 위에 "즉시 구매가" 라벨 한 줄 추가
    • fillCatGrid — 배지를 TODAY / NEW 문구로 통일
    • 찜 목록 — 가격 하락 시 내린 금액 + 원래 가격 취소선 출력

  4. sw.js — 버전 올리기

    클라이언트 파일(HTML·CSS·JS)이 바뀌었으므로 VERSION을 올려야 사용자 화면에 반영됩니다. 현재 값은 bellore-v178-ai-log입니다.

  5. DESIGN.md — 같이 고쳐야 함

    지금 문서와 이 시안이 정면으로 충돌하는 항목이 둘 있습니다. 작업하면서 함께 갱신해 주세요.

    • 1)색 — "카테고리 원형 아이콘 = 컬러(주황·초록·틸·파랑·보라)" → 흑백 + 액센트 1색으로 교체
    • 3)4)5) 규격 — 입력 52px/라운드 12px, CTA 54px/12px, 카드 14px → 44 / 52 / 0~2px로 교체

절대 건드리면 안 되는 것

  • 루트 CNAME 파일과 GitHub Pages 설정. bellore.co.kr이 여기로 서빙됩니다 — 지우면 즉시 404입니다.
  • 결제 금액 계산·검증 로직. 이번 작업은 표시만 바꿉니다. confirm-payment 등 서버 함수는 손대지 않습니다.
  • 전역 MutationObserver로 document.body 감시 금지. 과거에 스플래시가 멈춘 원인입니다.
  • 클래스 이름 변경 금지. script.js가 문자열로 HTML을 만들기 때문에 이름이 바뀌면 조용히 깨집니다.
  • 금액 한글표기(= 1,200만원)는 입력칸 오른쪽에서만. 카드·상세 같은 표시 화면에는 넣지 않습니다.
