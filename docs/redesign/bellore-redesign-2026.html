적용 순서

한 번에 전부 갈아엎지 않습니다. 매출에 바로 닿는 화면부터, 되돌리기 쉬운 단위로 나눠 배포합니다. 각 단계는 배포 후 실제 앱에서 구동 확인까지 끝낸 다음 다음 단계로 넘어갑니다.

  1. 공통 토큰 · 부품 정리

    색·글꼴·입력칸·버튼·카드 규격을 CSS 변수 한 곳으로 모읍니다. 화면은 그대로인데 들쭉날쭉만 사라지는 단계라 위험이 가장 낮습니다.

    화면 변화 없음 · 되돌리기 쉬움

  2. 상품 목록 · 상품 상세

    구매로 이어지는 화면부터. 카드 5줄 고정, 배지 통일, 상세 첫 화면에 보증·배송·구성품·상품번호 노출.

    전환율 직접 영향

  3. 홈 · 하단 탭바

    퀵메뉴 컬러 아이콘, 신뢰 스트립, 실시간 견적 보드, 가운데 '내 시계 팔기' 버튼. 전역 요소라 배포 후 실제 구동 확인 필수입니다.

    전역 변경 · 구동 확인 후 배포

  4. 비교견적 · 판매 신청 폼

    단계형 폼으로 전환, 금액 입력칸 한글 보조표기, 견적 카드 정렬. 폼 필드가 바뀌면 payload · DB 저장 · 카드 표시 · 서버 검증까지 함께 반영합니다.

    DB · 서버 함께 수정

  5. 마이페이지 · 결제

    마이 8칸 컬러 아이콘, 자산 카드, 결제 금액 분리 표기. 결제 화면은 금액 계산 로직을 건드리지 않고 표시만 바꿉니다.

    결제 로직 불변 · 표시만 변경

  6. PC 웹 · 관리자

    중앙 1180px 레이아웃, 푸터 법적 링크 정리, 관리자 화면의 과한 빨간 글씨 정리.

    마지막 단계

진행 전에 확인 부탁드립니다

  1. 배너 스타일 — 시안은 다크 그린 배경입니다. 구구스처럼 사진을 꽉 채운 배너로 갈지, 지금처럼 배경색 + 시계 이미지로 갈지 정해주세요.
  2. 하단 탭바 가운데 버튼 — '내 시계 팔기'로 넣었습니다. '비교견적'이 더 맞으면 바꾸겠습니다.
  3. 가격 표기 — 카드·상세는 16,500,000원(전체 표기)으로 했습니다. 바이버처럼 1,650만원으로 바꿀지 확인 부탁드립니다.
  4. 홈 실시간 견적 보드 — 노출할지 여부. 입찰 금액을 비회원에게도 보여줄지도 함께 정해주세요.
  5. 브랜드 순서 — 홈 10칸을 롤렉스 · 파텍 · AP · 까르띠에 · 오메가 순으로 넣었습니다. 매입 비중에 맞게 조정 가능합니다.
